# Gastos

App para cargar gastos personales y de empresa desde el celular, incluso sin señal.

- Se instala desde Safari con "Agregar a pantalla de inicio".
- Los gastos quedan guardados en el celular y se copian a una planilla de Google cuando hay conexión (ver `planilla/Codigo.gs`).
- Los gastos de empresa se mandan por WhatsApp como una imagen del ticket con el detalle impreso.
